## Objective

Regression tests for the salescall push section of `SyncService::push()`:

1. Payload mapping and mark-synced (`server_id` + `ref_number`).
2. Portal rejection → failed + attempts + `sync_error`, retryable.
3. Exhausted failed rows (`sync_attempts >= 3`) are not pushed again.
4. Dependency skips: customer only `queued` on Portal, itinerary without
   `local_uuid`.
5. 401 aborts the push with `token_expired` and leaves the row untouched.
